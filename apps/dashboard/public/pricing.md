# TCalc pricing

## Open-source core

- Price: $0
- License: MIT
- Account required: No
- Includes: VS Code extension, CLI, local model catalog, workspace scanning, model recommendations, repo maps, agent rules, reports, and the experimental local stdio MCP server.

TCalc does not proxy model requests or sell API access. If you choose to use a paid model provider in another tool, that provider's charges are separate from TCalc.
