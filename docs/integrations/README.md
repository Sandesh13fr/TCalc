# TCalc Integrations

Integration guides for using TCalc from AI coding tools.

## By Tool

| Tool | Method | Quick Start |
|------|--------|-------------|
| [Cursor](./cursor.md) | MCP + agent rules | Add `mcpServers` to `.cursor/mcp.json` |
| [Continue](./continue.md) | MCP | Add MCP server to `config.yaml` |
| [Claude Desktop](./claude-desktop.md) | MCP | Add MCP server to `claude_desktop_config.json` |
| [Claude Code](./claude-code.md) | MCP + `CLAUDE.md` | Run `wma mcp` or configure MCP client |
| [Cline](./cline.md) | MCP | Configure MCP in Cline settings |
| [Roo](./roo.md) | MCP | Configure MCP in Roo settings |
| [Generic MCP Client](./generic-mcp.md) | MCP | Any stdio MCP client |

All integrations are **local-first**: no telemetry, no cloud calls, no source upload.
