# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take security seriously. If you discover a vulnerability, please report it privately.

**Do not** open a public GitHub issue. Instead, email the project maintainer or open a security advisory at:

https://github.com/Sandesh13fr/TCalc/security/advisories/new

## Local-First Guarantee

TCalc is designed to be **local-first**. By default:

- No code leaves your machine
- No telemetry or analytics are collected
- No external API calls are made without explicit user action
- All model catalogs are bundled and loaded locally
- API keys for cloud models are stored in VS Code's secret storage or user config

If you discover any behavior that violates this guarantee, please report it immediately.
